Lección 2 · ~25 min · Python desde cero

Preguntar y convertir

Hacer que tu script pida datos al usuario y entender por qué "5" no es lo mismo que 5.

Lo que lograrás hoy Un script que te pide un dominio web y un número de páginas, arma la dirección completa y calcula cuánto tardaría en visitarlas con una pausa entre cada una.

Por qué esto importa para tu misión

Un script que descarga páginas casi siempre necesita datos que cambian: qué sitio visitar, cuántas páginas pedir. Hoy aprendes a recibirlos con input() y a evitar el error más común de quien empieza: mezclar texto con números.

Antes de seguir: recupera la lección 1

Intenta responder sin volver atrás.

¿Qué muestra este programa? Escribe exactamente lo que aparece en pantalla.

sitio = "python.org"
print("https://" + sitio)

El + une los dos textos, sin añadir espacios.

Cuatro ideas

1. input() pregunta y devuelve lo que el usuario escribe

Lo que escribe la persona llega siempre como texto, aunque sean dígitos.1

dominio = input("Dominio (ej. python.org): ")
print("Voy a visitar https://" + dominio)

2. Los valores tienen tipo, y type() te lo dice

print(type("5"))   # <class 'str'>     texto
print(type(5))     # <class 'int'>     entero
print(type(2.5))   # <class 'float'>   decimal

El tipo cambia lo que hacen los operadores. Con números, * multiplica; con texto, repite:1

print(5 * 2)       # 10
print("5" * 2)     # 55

3. int() y str() convierten entre tipos

int("5") convierte el texto en el número 5. str(5) hace lo contrario.1

paginas = int(input("¿Cuántas páginas? "))
print(paginas * 2)   # si escribes 5: 10

Si el texto no parece un número, la conversión falla:

int("abc")
ValueError: invalid literal for int() with base 10: 'abc'

4. Unir texto con número da un error, y se arregla convirtiendo

print("Total: " + 10)
TypeError: can only concatenate str (not "int") to str

print("Total: " + str(10))
Total: 10

Python lee el mensaje así: "solo puedo unir texto con texto, y me diste un entero". También existe len(), que cuenta los caracteres de un texto: len("https://python.org") da 18.1

Hazlo tú

  1. En la carpeta practica, crea visita.py con este contenido (escríbelo, no lo pegues; teclear fija mejor): 
    dominio = input("Dominio (ej. python.org): ")
paginas = int(input("¿Cuántas páginas quieres descargar? "))

print("Voy a visitar https://" + dominio)
print("Con 2 segundos de pausa por página tardaré", segundos, "segundos")

  2. Ejecútalo con python3 visita.py y responde python.org y 5. Deberías ver 10 segundos y 18 caracteres.
  3. Rómpelo. Cambia la línea de paginas a paginas = input("¿Cuántas páginas quieres descargar? ") (sin int), ejecútalo con 5 y observa qué pasa con segundos. Después restaura int(...).
  4. Un reto: añade una línea que muestre el tiempo en minutos usando / 60 (la división de Python). ¿Qué tipo de número devuelve?

La pausa de 2 segundos es una costumbre que importará mucho cuando pidamos páginas de verdad: más adelante veremos por qué no conviene pedirlas a toda velocidad.

Comprueba lo que recuerdas

El usuario escribe 5. ¿Qué muestra este programa? Escribe exactamente lo que aparece.

paginas = input("¿Cuántas páginas? ")
print(paginas * 2)

input() devuelve texto. Como paginas es el texto "5", multiplicarlo por 2 lo repite: 55. No es una suma ni un producto.

Esta línea da TypeError: can only concatenate str (not "int") to str. ¿Cuál la corrige?

print("Total: " + 10)
  • print("Total: " + str(10))
  • print("Total: " + int(10))
  • print("Total: " - str(10))
  • print("Total: " + (10))

Para unir con + ambos lados deben ser texto, así que el número se convierte con str(). int(10) sigue siendo un entero.

El usuario escribe abc cuando el programa pide un número. ¿Qué línea falla?

dominio = input("Dominio: ")
paginas = int(input("Páginas: "))
print("Listo")
  • Falla la segunda línea del programa
  • Falla la primera línea del programa
  • Falla la tercera línea del programa
  • No falla ninguna línea del programa

int("abc") lanza ValueError porque ese texto no es un número. Más adelante aprenderás a manejar ese caso sin que el programa se caiga.
