Tu primer script

Escribir un archivo, ejecutarlo y leer lo que Python te responde.

Lo que lograrás hoy Crear un archivo hola.py, ejecutarlo desde la terminal y verlo imprimir un mensaje que usa una variable.

Por qué empezar aquí

Tu meta es que un programa vaya a la web por ti: descargue una página, consulte una API y guarde el resultado. Ese programa será un script: un archivo de texto con instrucciones que Python ejecuta una tras otra, de arriba abajo. Antes de traer nada de internet necesitas dominar el ciclo básico: escribir, ejecutar, leer el resultado.

Tres ideas

1. print() muestra algo en pantalla

El texto va entre comillas. Sin comillas, Python cree que te refieres a un nombre.

print("Hola, mundo")
# Hola, mundo

2. Una variable es un nombre con un valor guardado

El signo = no compara: guarda el valor de la derecha bajo el nombre de la izquierda. Si lo guardas otra vez, el valor anterior se pierde.1

nombre = "Ana"
print("Hola, " + nombre)
# Hola, Ana

nombre = "Luis"
print("Hola, " + nombre)
# Hola, Luis

print("nombre")
# nombre   (con comillas es solo la palabra, no la variable)

El signo + entre dos textos los une. Fíjate en el espacio dentro de "Hola, ": Python no añade espacios por ti.

3. Los errores son información, no fracasos

Python se detiene y te dice qué línea falló y por qué. El libro lo resume con un título: "Errors Are Okay!".1 Por ejemplo, si olvidas cerrar las comillas: 

print("Hola)
    print("Hola)
          ^
SyntaxError: unterminated string literal (detected at line 1)

El ^ señala dónde empieza el texto que nunca se cerró. Aprender a leer estos mensajes te ahorrará más tiempo que cualquier otra habilidad de hoy.

Hazlo tú

Estos pasos asumen macOS y Python ya instalado (en tu equipo es python3, versión 3.14).

  1. Abre la app Terminal. Comprueba que Python responde: 
    python3 --version
  2. Entra en la carpeta del curso y crea una carpeta para practicar: 
    cd ~/minicurso-python-teach
mkdir practica
cd practica
  3. Crea el archivo con un editor de texto plano (VS Code, o nano hola.py en la terminal; con nano se guarda con Ctrl+O, Enter y se sale con Ctrl+X). Escribe: 
    tu_nombre = "escribe aquí tu nombre"
print("Hola, " + tu_nombre)
print("Hoy empiezo a aprender Python")
  4. Ejecútalo: 
    python3 hola.py
  5. Rómpelo a propósito. Borra las comillas finales de la primera línea, ejecuta de nuevo y lee el error. Luego arréglalo.

Comprueba lo que recuerdas

Responde sin mirar arriba. Si fallas, es buena señal: el esfuerzo de recordar es lo que fija el aprendizaje.

¿Qué muestra este programa? Escribe exactamente lo que aparece en pantalla.

ciudad = "Lima"
ciudad = "Quito"
print(ciudad)

La segunda línea guarda "Quito" en ciudad y el valor "Lima" se pierde.

Con estas dos líneas, ¿qué hace la tercera?

nombre = "Ana"
print("nombre")
  • Muestra la palabra nombre
  • Muestra la palabra Ana
  • Muestra la palabra print
  • Muestra la palabra texto

Con comillas es solo texto. Sin comillas, print(nombre) mostraría Ana.

Ejecutas print("Hola) y Python responde SyntaxError: unterminated string literal. ¿Qué pasa?

  • Falta cerrar las comillas del texto
  • Falta guardar el archivo en la carpeta
  • Falta poner una variable antes del texto
  • Falta escribir print en mayúsculas

"Unterminated string literal" significa texto sin terminar: las comillas se abrieron y nunca se cerraron.
