Reading an error

  1. Look at the last line: the error type and its description.
  2. Look at the line number Python gives.
  3. The ^ points to the approximate place of the problem.
MessageMeans
SyntaxError: unterminated string literalQuotes were opened and never closed.
TypeError: can only concatenate str (not "int") to strYou tried to join text with an integer using +. Convert with str().
ValueError: invalid literal for int() with base 10: 'abc'int() received a text that isn't a number.
